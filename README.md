# SPL Library (Android)

Lightweight native Android app (Kotlin + Jetpack Compose) for the Seattle Public Library using BiblioCommons APIs directly from the device.

## Features
- Search the SPL catalog with Physical Books filter on by default (plus All Physical / All Formats)
- Browse newly acquired books (30d / 90d / 6m) and sort by relevance, newly acquired, or publication date
- 1-Touch Holds using a saved default SPL pickup branch
- View active holds with queue position, Ready for Pickup / In Transit status, pickup branch, and cancel hold
- View current checkouts sorted by due date with one-tap renewal
